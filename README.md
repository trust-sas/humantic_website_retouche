# Humantic - Site Web Officiel

Bienvenue sur le dépôt du code source du site web de **Humantic**, une association à but non lucratif œuvrant pour l'humanitaire à travers les TIC (Technologies de l'Information et de la Communication).

## 🌍 À propos

Humantic s'engage à réduire la fracture numérique et à apporter une aide humanitaire via la technologie. Ce site vitrine présente nos missions, notre équipe, nos domaines d'expertise,notre programme de bénévolat /programe de volontariat et la possibilité de faire un don.

## 🛠️ Technologies

Ce projet est un site statique simple construit avec :

- **HTML5**
- **CSS3** (avec variables CSS pour le thème)
- **Bootstrap 5.3** (pour la grille les composants de base et les fenetres modales )
- **FontAwesome** (pour les icônes)
- **JavaScript** (pour la navigation , les animations , la validation des formulures )

## 🚀 Installation & Lancement

Aucune installation complexe n'est requise.

1. Clonez ce dépôt :
   ```bash
   git clone <votre-url-repo>
   ```
2. Ouvrez le fichier `index.html` dans votre navigateur préféré(ou utilisez l'extension "live server" de VS Code pour un rendu plus fidèle).

3. Naviguez vers les autres pages via le menu du site.

## 📂 Structure

- `/assets/images` : Images des sections, photos d'equipe et logos.
- `/css` : Feuilles de style unique, partagée par toutes les pages (style.css).
- `/js` : Scripts JavaScript partagés (main.js) avec la navigation , animations , formulaires.
- `index.html` : Page d'accueil (missions, expertise, équipe, contact, don).
- `benevolat.html` : page de programme de volontariat & partenariat.

## ✨ Fonctionnalités

- Page d'accueil : présentation de l'association, statistiques animées au scroll, domaines d'expertise (Formation, Assistance, Inclusion), équipe, formulaire de contact.
- Programme de Volontariat (benevolat.html) : présentation des opportunités de bénévolat, prérequis recherchés, et formulaire de candidature avec validation du numéro de téléphone.
- Faire un Don : bouton flottant accessible depuis toutes les pages, ouvrant une fenêtre de don avec choix du montant, calcul de l'impact, méthode de paiement (Mobile Money) et validation du numéro de téléphone.

## 🎨 Design

Le design met l'accent sur l'élégance et la modernité ("Clean & Tech") en utilisant une palette :

- **Bleu Profond** (Confiance, Tech)
- **Ambre/Orangé** (Humanité, Espoir, Energie)
