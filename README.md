# Humantic - Site Web Officiel

Bienvenue sur le dépôt du code source du site web de **Humantic**, une association à but non lucratif œuvrant pour l'humanitaire à travers les TIC (Technologies de l'Information et de la Communication).

## 🌍 À propos
Humantic s'engage à réduire la fracture numérique et à apporter une aide humanitaire via la technologie. Ce site vitrine présente nos missions, notre équipe, et nos domaines d'expertise.

## 🛠️ Technologies
Ce projet est un site statique simple construit avec :
- **HTML5**
- **CSS3** (avec variables CSS pour le thème)
- **Bootstrap 5.3** (pour la grille et les composants de base)
- **FontAwesome** (pour les icônes)
- **JavaScript** (pour interactions mineures)

## 🚀 Installation & Lancement
Aucune installation complexe n'est requise.

1. Clonez ce dépôt :
   ```bash
   git clone <votre-url-repo>
   ```
2. Ouvrez le fichier `index.html` dans votre navigateur préféré.

## 📂 Structure
- `/assets/images` : Images et logos.
- `/css` : Feuilles de style (style.css).
- `/js` : Scripts JavaScript (main.js).
- `index.html` : Page d'accueil unique.

## 🎨 Design
Le design met l'accent sur l'élégance et la modernité ("Clean & Tech") en utilisant une palette :
- **Bleu Profond** (Confiance, Tech)
- **Ambre/Orangé** (Humanité, Espoir, Energie)
